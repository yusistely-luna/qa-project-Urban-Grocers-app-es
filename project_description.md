# Urban Grocers Project 

## Description
This project contains automated API tests to validate the `name` parameter during the creation of a new kit for a user in the Urban Grocers application, using Python and Pytest.

## Documentation
https://cnt-f60568cb-9352-4d7c-a43f-929bedb4878c.containerhub.tripleten-services.com/docs/

## Technologies Used
- Python 3.14
- Pytest 9.1.1
- Requests 2.34.2

## Project Structure
- configuration.py — API URL and endpoints.
- data.py — Test data and request bodies.
- sender_stand_request.py — Functions for sending API requests.
- create_kit_name_kit_test.py — Automated tests for kit creation.

## How to Run the Tests
1. Open the project in PyCharm
2. Install the required packages:
   ```bash
   pip install pytest requests
3. Run all tests using the `pytest` command.
